## 为什么选择 Hexo

Markdown 写作、静态部署、生态成熟，对个人博客来说是性价比最高的方案之一。

## 自研主题的取舍

现成主题功能很全，但首页全屏壁纸、随想瀑布流这类强定制需求，自己写主题反而更快。

```bash
hexo new "我的第一篇文章"
hexo server
```
