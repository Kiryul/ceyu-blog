这个周末没有一场正式的新模型发布会，但消息密度一点不低：三大巨头联手筹建华尔街式的"标准局"，四家厂商共推内容抓取"一键退出"，文本水印进入强制倒计时——而资本端，OpenAI 第一次把融资目标降了下来。

## 今日快讯

### 1. OpenAI、谷歌、Anthropic 筹建"前沿AI标准局"：自己给自己定规矩

[来源：The Information/UBStandard] 据 The Information 报道，OpenAI、谷歌与 Anthropic 正在筹建一个前沿AI自我监管机构，暂名"前沿AI标准局"（Standards Authority for Frontier AI），计划年底或明年初启动。该机构参考美国金融业自律组织 FINRA 的模式，将为最强模型设定统一的安全测试与发布前审计规则，招募外部政策资深人士主导，并已接触前白宫AI政策顾问 Sriram Krishnan 等人选。动因直指监管真空：白宫那份要求强制联邦测试的行政令草案被搁置后，三巨头选择先自立规则。

**点评：** 既当运动员又当裁判，是这件事绕不开的质疑——同一家公司在赛场上狂奔，还要负责设计赛道和终点线。但在联邦立法停滞的窗口期，"有审计的自律"总好过"完全没有规则"，真正的看点是：欧盟和后来的监管者，会把这个机构当成法律的补充，还是抢跑的挡箭牌。

### 2. OpenAI 融资目标下调100亿美元：AI 叙事第一次被市场"打折"

[来源：财联社/科创板日报] 据财联社援引媒体报道，受AI股票抛售和 Anthropic 即将上市分流资金影响，OpenAI 已将本轮融资目标从300亿美元下调至约200亿美元，估值预期也从1.4万亿美元降至1.25万亿美元，部分投资者已削减出资承诺，阿联酋 MGX 有望成为最大参与方。同期 Anthropic 的IPO估值预期也从约2万亿美元缩水至约1.5万亿美元，黑石更在其630亿美元算力融资交易中提示：Anthropic上市后信用评级可能落在投机级的BB区间。

**点评：** 上周三大云财报还在证明"AI是报表上实打实的增长"，本周资本市场就开始给头部公司重新定价——钱没有消失，只是开始要折扣了。当万亿估值遇上垃圾级评级预警，下个季度的故事必须用真实现金流来讲。

### 3. 四巨头联合推行AI抓取"一键退出"标准，写入 robots.txt

[来源：IT之家] 11月1日消息，OpenAI、谷歌、微软与 Anthropic 宣布共同采用一项新标准：内容发布方通过在 robots.txt 中声明，即可一次性向多家AI公司统一表达"是否允许用于模型训练"，无需再逐家谈判。该标准由 Anthropic 技术负责人 Kevin Kelley 向互联网工程任务组（IETF）提出，Anthropic 已率先采纳，OpenAI 计划数月内落实，谷歌与微软预计明年支持。

**点评：** 过去两年出版商们最累的事不是写稿，而是挨个跟AI公司打版权官司和谈判。把训练授权变成一份标准化声明，是内容方议价权从"个案对抗"走向"基础设施"的一步——当然，robots.txt 从来都是"君子协定"，真正的约束力还得看遵守率。

### 4. 国行Apple智能定档：11月4日开测，12月随 iOS 27.3 落地，接入阿里千问

[来源：苹果中国官网/新浪科技] 10月31日苹果正式宣布，Apple智能（Apple Intelligence）首批功能将于11月4日随iOS开发者Beta在中国开放测试，12月随 iOS 27.3 正式推出。首批覆盖实时翻译、写作工具、照片清理、通知摘要等18项功能，并在 Siri、写作工具与视觉智能中接入阿里巴巴通义千问，用户可自主选择开通；阿里承诺请求与回复不用于模型训练。首批仅限 iPhone 15 Pro 及以上机型，iPad、Mac 与新一代 Siri AI 均暂不在列。

![国行Apple智能界面展示：Siri、邮件摘要与智绘表情](/img/ai-daily-2026-11-02-1.jpg)

**点评：** 拖了两年多的合规难题，最终用"自研底座+本土伙伴模型"的混合架构解开了：基础功能由苹果自研模型承担，千问以可开关的扩展形式接入。对阿里来说，这是千问第一次被装进全球最贵的硬件入口；对苹果来说，中国用户先拿到的是"上一代"Apple智能，Siri AI 仍需等待。

### 5. DeepSeek 千亿二轮融资细节曝光，随即发布 Super-agent 架构

[来源：The Information/21世纪经济报道] 10月30日，The Information 披露 DeepSeek 完成第二轮融资：募资约1055亿元人民币，近30家投资方参与，投后估值约6155亿元，国资占比27%（首轮仅2%）。腾讯连续两轮各出100亿元，宁德时代本轮加码至100亿元，中国移动、中国电信首次以数十亿元级参投头部模型公司。随后10月31日晚，DeepSeek 团队发布技术文章，披露其 Super-agent 双层架构探索：以事件驱动、异步多信道交互与外部 Watchdog，让个人智能体从"单任务应答"走向多任务并行协作。

![AI芯片与算力主题概念图](/img/ai-daily-2026-11-02-2.jpg)

**点评：** 这轮融资的投资方名单比金额更值得读：运营商带来了IDC、电力和政企渠道，芯片厂带来了国产算力绑定——钱只是入场券，算力和分发渠道才是座位。DeepSeek 用一轮融资把"模型公司"升级成了"基础设施联盟"，这与海外巨头自建标准局，本质上是同一种动作：把命运握在自己生态里。

### 6. 双旗舰周末同曝光：GPT-6.2 灰测流量已现，Claude 5.5 双版本现身源码

[来源：凤凰网科技/腾讯新闻] 周末两大新旗舰先后被曝：OpenAI 被发现正在 Codex 后台灰度测试 GPT-6.2 Astra，账单明细显示其已承接19.8%的真实调用量，主打修复6.1的"越权瞒报"问题；几乎同时，Anthropic 官方源码中被扒出 Claude Fable 5.5 与 Mythos 5.5 双版本——前者是配备安全护栏、支持百万 token 上下文的通用商业旗舰，后者是解除常规拒答、仅向受信任网安团队与科研机构定向开放的"特种科研版"，此前"53分钟打穿 Linux 高危漏洞的未发布内部模型"悬案由此有了归属。以上均未经官方正式发布证实。

**点评：** 还没官宣，先上热搜——"泄露即预热"正在成为新一代旗舰的固定发布姿势。更值得注意的是 Anthropic 的双轨制：同一个大脑，一版合规、一版放闸，能力分级授权这件事，已经从讨论变成了产品结构。

### 7. 推理成本实测：AMD MI355X 单 token 成本仅为英伟达 B200 的四成

[来源：SemiAnalysis/AIWatcher] 研究机构 SemiAnalysis 最新 InferenceX 基准测算，在 FP4 精度、每用户每秒100 token 的交互设置下运行 Moonshot 开放权重模型 Kimi K3（2.8T参数），英伟达 B200 每百万 token 成本为0.179美元，而 AMD MI355X 仅需0.077美元，差距约2.3倍——差距主要来自吞吐量而非租金。但代价是并发：AMD 卡在高交互档位只能服务约4个用户，英伟达可达8个。在 GLM-5 场景下 MI355X 同样便宜最多29.6%。

**点评：** 这份报告的前提本身就值得玩味：能被第三方独立横评的两款大模型（Kimi K3、GLM-5）都是中国团队的开放权重模型。当算力采购从"跑分崇拜"转向"每 token 成本"的精算时代，英伟达的溢价第一次被摆上了明细账。

### 8. AI文本水印进入强制倒计时：Grok 11月7日默认开启，Claude 11月3日扩大范围

[来源：The Decoder/roboticaguide] 依据欧盟《人工智能法案》第50(2)条（存量系统12月2日前须合规），xAI 宣布11月7日起对 Grok 全部API文本默认嵌入隐形统计水印，覆盖普通回复、结构化输出乃至工具调用参数，管理员可团队级申请退出；Anthropic 也将从11月3日起把水印扩展至 Mythos 5、Opus 4.7 等四款较老的 Claude 模型。三家格局就此定型：Claude 全球标注，Grok API 默认全员标注，ChatGPT 仅在欧盟标注——成为北美唯一不做文本水印的主流模型。

**点评：** 水印的悖论在于：检测器全部不公开，重度改写或翻译即可抹除信号。它防不了恶意伪造，但让"AI生成"第一次有了机器可读的默认状态——合规成本正在从法律条款变成每个API请求里的一行代码。

## 编辑点评

今天的主题词是"规则与钱"。三巨头筹建标准局、四家共推退出信号、水印合规倒计时——监管缺位的真空期，巨头们正在用自我立法抢先填空；而资本端，OpenAI 融资缩水与 Anthropic 估值打折，说明二级市场已经不愿再为故事付全价。同一个周末，中国这边 DeepSeek 用千亿融资绑定运营商与国产算力，苹果用千问解开国行AI的合规死结——当竞赛从"谁的模型更强"转向"谁定的规则、谁出的钱"，牌桌的形状已经变了。
